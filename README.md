# Minecraft Changelog Website: Block Maps Changelogs

Sito web per i changelog della custom map Minecraft.

## Modalità manutenzione

Per mostrare `offline.html` a chi visita il sito, apri `status.js`, imposta `maintenanceMode` su `true` e pubblica la modifica. Per riaprire il sito, riportalo a `false` e pubblica di nuovo.

La modalità funziona tramite JavaScript nel browser: non sostituisce un blocco lato server e non può impedire l'accesso a contenuti già memorizzati nella cache o con JavaScript disattivato.
